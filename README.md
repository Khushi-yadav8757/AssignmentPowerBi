# 📊 Hospital Patient Satisfaction Dashboard

![Hospital Patient Satisfaction Dashboard](https://github.com/Khushi-yadav8757/AssignmentPowerBi/blob/main/khushi_yadav.png)

## 📌 About the Project

An interactive **Power BI dashboard** built using HCAPS data to analyze hospital patient satisfaction, survey response rates, state-wise performance, and trends over time.

## 🎯 Key Highlights

- 📊 Patient Satisfaction Analysis
- 📈 Response Rate Trends
- 🗺️ State-wise Performance Analysis
- 🎯 KPI Dashboard
- 🤖 Power BI Key Influencers
- 🔍 Interactive Filters & Tooltips
- 🧹 Data Cleaning & Transformation
- 📐 Data Modeling

## 🛠️ Tools Used

- Microsoft Power BI
- Power Query
- DAX
- HCAPS Dataset
- GitHub

## 📊 Dashboard

The dashboard provides insights into:

- Average Top Box Score
- Average Middle Box Score
- Average Response Rate
- Total Surveys
- Patient satisfaction by measure
- Response rate by state
- Response trends over release periods

## 💡 Key Insights

- Identified states with higher response rates.
- Analyzed patient satisfaction across healthcare measures.
- Observed response-rate trends over time.
- Used AI-based Key Influencers to identify factors associated with response rates.
